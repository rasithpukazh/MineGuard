# MineGuard – SIH 2026

**Offline-First Mine Vehicle Safety System**

## Problem
Dense fog and low visibility in open-cast mines make vehicle movement difficult and increase collision risks.

## Proposed Solution
MineGuard combines a mine-specific digital map, GPS, IMU and a vehicle monitoring dashboard to support road-aware safety warnings.

## Current Prototype
- ESP32 microcontroller
- GNSS/GPS module
- MPU6050 IMU
- Buzzer-based warning
- Laptop-based monitoring dashboard

## System Workflow
GPS and IMU → ESP32 → USB Serial Communication → Custom Mine Map Dashboard → Safety Status and Alerts

## Planned Enhancements
- Vehicle-to-vehicle communication
- Roadside safety units
- mmWave radar integration
- Advanced obstacle detection
